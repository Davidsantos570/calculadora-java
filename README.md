# 🧮 Calculadora em Java

Este projeto foi desenvolvido como parte dos meus estudos em **Análise e Desenvolvimento de Sistemas**, focado em consolidar fundamentos de lógica de programação e sintaxe Java.

## 🚀 Funcionalidades
- Operações matemáticas básicas: Soma, Subtração, Multiplicação e Divisão.
- **Tratamento de Erros:** Implementação de lógica para impedir a divisão por zero.
- **Interação via Console:** Uso da classe `Scanner` para entrada de dados.

## 🧠 Competências Aplicadas
- **Lógica de Programação:** Estruturas de decisão (`switch-case` e `if-else`).
- **Atenção aos Detalhes:** Garantia de precisão nos cálculos com o tipo `double`.
- **Gestão de Processos:** Código organizado para facilitar a manutenção.

## 🛠️ Tecnologias
- Java (JDK 17 ou superior)
- IDE (VS Code / IntelliJ)
